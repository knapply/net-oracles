# Burt constraint {#concept-top}

Family: [Roles and positions](index.html). Subfamily: Structural holes and brokerage. Concept id: `burt_constraint`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(z_{ij}\)</td><td>strength of the tie between \(i\) and \(j\): 1 for a binary tie, a weight for valued data, the sum over parallel edges</td></tr><tr><td>\(p_{ij}=\frac{z_{ij}+z_{ji}}{\sum_{k\ne i}(z_{ik}+z_{ki})}\)</td><td>share of \(i\)'s total tie volume invested in \(j\) (loops excluded)</td></tr><tr><td>\(N(i)\)</td><td>contacts of \(i\): nodes \(j\ne i\) with \(p_{ij}&gt;0\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Burt constraint. Entries grouped here: Constraint.

<div class="formula-block"><p class="formula-name"><strong>Dyadic constraint (Burt 1992)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[c_{ij}=\Bigl(p_{ij}+\sum_{q\ne i,j}p_{iq}p_{qj}\Bigr)^2\]</div><p class="formula-where">Constraint exerted on \(i\) by contact \(j\) directly and through shared contacts.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Aggregate constraint (Burt 1992)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[C_i=\sum_{j\in N(i)}c_{ij}\]</div><p class="formula-where">Sum over the contacts of \(i\). Defined for nodes with at least one contact; for a node without contacts the sum is empty and \(p_{ij}\) has a 0 denominator, so it is not defined. For a binary graph, with one contact the value is 1.</p></div>

- <a id="why-constraint-networkx"></a>**[NetworkX](../../tools/networkx.html)** <a class="st st-t st-conv" href="../../method.html#state-checked-convention"><span class="g" aria-hidden="true">≠</span>checked, differs by convention</a> NetworkX 3.7 was run and its value differs from the reference value by convention (defaults, self-loops, ties and weights) on inputs tagged loops. constraint: NetworkX keeps self-loops in the adjacency matrix, so a loop adds to the node's total tie volume and lowers every p\_ij. Burt's measure concerns ties to others; this reference and igraph ignore loops. constraint\_weighted: A node whose only tie is a self-loop has no neighbours, so Burt's constraint is undefined for the reference value and the definition oracle; NetworkX counts the loop as a tie to itself (4 for one loop of weight 2). No mapping that reproduces the tool's value is recorded, so the entry was not compared after mapping. Tolerance before mapping: abs 1e-12, rel 1e-12 (0 means exact equality). 2 comparisons differ and 33 agree.
