# Ego network density {#concept-top}

Family: [Ego networks](index.html). Subfamily: Ego measures. Concept id: `ego_density`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>simple graph (parallel edges merged, loops dropped) with node set \(V\); each edge has a source and a target</td></tr><tr><td>\(v\)</td><td>the ego, a node of \(V\)</td></tr><tr><td>\(N_k(v)\)</td><td>alters of \(v\) within \(k\) steps: \(\{u\ne v: d(v,u)\le k\}\); for a directed graph the steps follow edge directions out of \(v\) (out version), into \(v\) (in version) or ignore direction</td></tr><tr><td>\(t_k(v)\)</td><td>number of ties among the alters, as in the ties entry</td></tr><tr><td>\(s=|N_k(v)|\)</td><td>number of alters</td></tr></tbody></table></div>

## Definition {#concept-definition}

Ego network density. Entries grouped here: Ego\_summary / density.

<div class="formula-block"><p class="formula-name"><strong>Ego network density</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\Delta(v)=\frac{t_1(v)}{\binom{s}{2}}\;\text{(undirected)},\qquad \Delta(v)=\frac{t_1(v)}{s(s-1)}\;\text{(directed)}\]</div><p class="formula-where">Fraction of possible ties among the alters that are present (ego excluded); defined only for \(s\ge 2\), since the denominator is 0 for fewer than two alters.</p></div>
