# Ego size {#concept-top}

Family: [Ego networks](index.html). Subfamily: Ego measures. Concept id: `ego_size`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>simple graph (parallel edges merged, loops dropped) with node set \(V\); each edge has a source and a target</td></tr><tr><td>\(v\)</td><td>the ego, a node of \(V\)</td></tr><tr><td>\(N_k(v)\)</td><td>alters of \(v\) within \(k\) steps: \(\{u\ne v: d(v,u)\le k\}\); for a directed graph the steps follow edge directions out of \(v\) (out version), into \(v\) (in version) or ignore direction</td></tr></tbody></table></div>

## Definition {#concept-definition}

Number of nodes within a range of steps from each node (ego included when the range starts at 0).

<div class="formula-block"><p class="formula-name"><strong>Ego size</strong> <span class="applies">applies to: any</span></p><div class="formula">\[s_k(v)=|N_k(v)|\;(+\,1\text{ when the ego is counted})\]</div><p class="formula-where">Number of alters within k steps (k=1: the neighbours). Whether the ego itself is counted is a reporting choice, so both values are stated; defined for every node, 0 alters for an isolate.</p></div>

<div class="table-wrapper"><table class="variants"><thead><tr><th>Variant</th><th>Measure id</th><th>Tools</th><th>What changes</th></tr></thead><tbody><tr><td><a href="#ego_size">Ego size</a></td><td><code>ego_size</code></td><td>3</td><td>The measure scores the number of nodes within a given range of steps, ego included when the range starts at 0: \(|N_k(v)|+1\) in the forms ego_size (k=1, direction ignored), ego_size_out and ego_size_in (directed steps) and ego_size_order2 (k=2).</td></tr></tbody></table></div>
