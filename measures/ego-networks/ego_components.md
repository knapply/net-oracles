# Ego network components {#concept-top}

Family: [Ego networks](index.html). Subfamily: Ego measures. Concept id: `ego_components`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>simple graph (parallel edges merged, loops dropped) with node set \(V\); each edge has a source and a target</td></tr><tr><td>\(v\)</td><td>the ego, a node of \(V\)</td></tr><tr><td>\(N_k(v)\)</td><td>alters of \(v\) within \(k\) steps: \(\{u\ne v: d(v,u)\le k\}\); for a directed graph the steps follow edge directions out of \(v\) (out version), into \(v\) (in version) or ignore direction</td></tr></tbody></table></div>

## Definition {#concept-definition}

Ego network components. Entries grouped here: Ego\_summary / components.

<div class="formula-block"><p class="formula-name"><strong>Components of the ego network without ego</strong> <span class="applies">applies to: any</span></p><div class="formula">\[c_k(v)=\#\,\mathrm{components}\bigl(G[N_k(v)]\bigr)\]</div><p class="formula-where">Number of (weakly, for directed graphs) connected components of the subgraph induced by the alters, ego removed. 0 when there are no alters.</p></div>
