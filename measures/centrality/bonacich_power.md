# Bonacich power centrality {#concept-top}

Family: [Centrality](index.html). Subfamily: Spectral and walk-based. Concept id: `bonacich_power`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(A\)</td><td>adjacency matrix: \(A_{uv}\) is the number (or total weight) of edges from \(u\) to \(v\)</td></tr><tr><td>\(\lambda_1\)</td><td>largest eigenvalue of \(A\)</td></tr><tr><td>\(\beta\)</td><td>attenuation exponent (may be negative)</td></tr><tr><td>\(\alpha\)</td><td>scaling constant chosen so that \(\sum_ic_i^2=n\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Bonacich power centrality of every node for a given attenuation exponent.

<div class="formula-block"><p class="formula-name"><strong>Power centrality (Bonacich 1987)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[c(\alpha,\beta)=\alpha\,(I-\beta A)^{-1}A\,\mathbf 1\]</div><p class="formula-where">Weighted sum of walks of all lengths: \(\sum_{k\ge0}\beta^kA^{k+1}\mathbf 1\). Positive \(\beta\) rewards connections to well-connected nodes; negative \(\beta\) rewards connections to poorly connected ones. Needs \(|\beta|&lt;1/|\lambda_1|\) for the series, and \(I-\beta A\) non-singular for the solution.</p></div>
