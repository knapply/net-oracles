# Gil-Schmidt power index {#concept-top}

Family: [Centrality](index.html). Subfamily: Local and structural scores. Concept id: `gil_schmidt_power`. 1 measure.

## Notation {#concept-notation}

## Definition {#concept-definition}

Gil-Schmidt power index. Entries grouped here: Gilschmidt.

<div class="formula-block"><p class="formula-name"><strong>Gil-Schmidt power index (Gil and Schmidt 1996)</strong> <span class="applies">applies to: any, normalized</span></p><div class="formula">\[P(v)=\frac{\sum_{i\in R(v)}1/d(v,i)}{|R(v)|}\qquad (P(v)=0\text{ if }R(v)=\emptyset)\]</div><p class="formula-where">Mean inverse distance over the reachable nodes: 1 when \(v\) is adjacent to every node it reaches; the smallest nonzero value is \(1/(n-1)\). Without normalization the sum \(\sum_{i\in R(v)}1/d(v,i)\) is returned (Sinclair 2007 discusses its centralization).</p></div>
