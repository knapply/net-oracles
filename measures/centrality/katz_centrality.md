# Katz centrality {#concept-top}

Family: [Centrality](index.html). Subfamily: Spectral and walk-based. Concept id: `katz_centrality`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(A\)</td><td>adjacency matrix: \(A_{uv}\) is the number (or total weight) of edges from \(u\) to \(v\)</td></tr><tr><td>\(\lambda_1\)</td><td>largest eigenvalue of \(A\)</td></tr><tr><td>\(\alpha\)</td><td>attenuation factor, \(\alpha&lt;1/\lambda_1\)</td></tr><tr><td>\(\beta\)</td><td>constant added to every node (1 by default)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Katz centrality of every node by fixed-point iteration (Katz 1953).

<div class="formula-block"><p class="formula-name"><strong>Katz status index (Katz 1953)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[x=\sum_{k=1}^{\infty}\alpha^k(A^{\mathsf T})^k\mathbf 1\]</div><p class="formula-where">Counts walks ending at a node, attenuated by \(\alpha\) per step.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Fixed-point form</strong> <span class="applies">applies to: any</span></p><div class="formula">\[x=\alpha A^{\mathsf T}x+\beta\mathbf 1\ \Longleftrightarrow\ x=\beta\,(I-\alpha A^{\mathsf T})^{-1}\mathbf 1\]</div><p class="formula-where">Adds the constant \(\beta\) to every node, so it equals \(\beta\mathbf 1\) plus the sum above (for \(\beta=1\)). Solved by iteration or by a linear system; converges when \(\alpha&lt;1/\lambda_1\).</p></div>
