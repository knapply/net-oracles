# Centralization {#concept-top}

Family: [Centrality](index.html). Subfamily: Centralization and tables. Concept id: `centralization`. 6 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(n=|V|\)</td><td>number of nodes</td></tr><tr><td>\(C(v)\)</td><td>centrality score of node \(v\) under the chosen measure (degree, closeness, betweenness or eigenvector centrality)</td></tr><tr><td>\(C^*\)</td><td>largest score, \(\max_v C(v)\)</td></tr><tr><td>\(T_{\max}\)</td><td>largest possible value of \(\sum_v (C^*-C(v))\) over graphs with \(n\) nodes (attained by a star for the measures below)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Freeman centralization of degree, betweenness, closeness or eigenvector centrality.

<div class="formula-block"><p class="formula-name"><strong>Freeman centralization (1978)</strong> <span class="applies">applies to: any, normalized</span></p><div class="formula">\[C_X=\frac{\sum_{v}\bigl(C^*-C(v)\bigr)}{T_{\max}}\]</div><p class="formula-where">Variation of the node scores around the largest, as a share of the largest variation possible; 0 for a graph in which all scores are equal, 1 for a star.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Theoretical maximum, degree (undirected)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[T_{\max}^{\deg}=(n-1)(n-2)\]</div><p class="formula-where">Star with raw degrees: centre \(n-1\), leaves 1.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Theoretical maximum, betweenness (undirected, raw scores)</strong> <span class="applies">applies to: undirected, raw</span></p><div class="formula">\[T_{\max}^{B}=\frac{(n-1)^2(n-2)}{2}\]</div><p class="formula-where">Star: centre \((n-1)(n-2)/2\), leaves 0.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Theoretical maximum, closeness (undirected, normalized scores)</strong> <span class="applies">applies to: undirected, normalized</span></p><div class="formula">\[T_{\max}^{C}=\frac{(n-1)(n-2)}{2n-3}\]</div><p class="formula-where">Star with normalized closeness: centre 1, leaves \((n-1)/(2n-3)\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Theoretical maximum, eigenvector</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[T_{\max}^{E}=n-2\]</div><p class="formula-where">The value recorded for the convention that scales scores to maximum 1; it is 0 for \(n=2\).</p></div>
