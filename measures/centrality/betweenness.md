## Definition {#concept-definition}

Shortest-path betweenness of every node (Brandes 2001).

<div class="formula-block"><p class="formula-name"><strong>Betweenness (Freeman 1977)</strong> <span class="applies">applies to: directed, raw</span></p><div class="formula">\[C_B(v)=\sum_{\substack{s\ne v\ne t\\ s,t\in V}}\frac{\sigma_{st}(v)}{\sigma_{st}}\]</div><p class="formula-where">Sum over ordered pairs \((s,t)\) with \(\sigma_{st}&gt;0\). For an undirected graph each unordered pair is counted once, so the value is half of this sum. Pairs without a path are not terms of the sum.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Normalized betweenness</strong> <span class="applies">applies to: normalized</span></p><div class="formula">\[C_B'(v)=\frac{C_B(v)}{(n-1)(n-2)}\ \text{(directed)},\qquad C_B'(v)=\frac{C_B(v)}{(n-1)(n-2)/2}\ \text{(undirected)}\]</div><p class="formula-where">Divides by the number of pairs of other nodes, so the value lies in \([0,1]\) and is 1 for the centre of a star. Needs \(n\ge 3\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Accumulation of dependencies (Brandes 2001)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\delta_s(v)=\sum_{w:\,v\in P_s(w)}\frac{\sigma_{sv}}{\sigma_{sw}}\bigl(1+\delta_s(w)\bigr),\qquad C_B(v)=\sum_{s\ne v}\delta_s(v)\]</div><p class="formula-where">Computes the same values as the first formula with one shortest-path search per source; the sum over \(s\) runs over ordered pairs, so an undirected graph's value is halved. Weighted graphs use Dijkstra's search with positive lengths.</p></div>

## Twomode / betweenness {#twomode-betweenness}

Measure id: `twomode:betweenness`. Original family: Two-mode and bipartite.

**Definition.** Betweenness of every node in a two-mode network, optionally divided by the largest possible value (Borgatti and Everett 1997).
