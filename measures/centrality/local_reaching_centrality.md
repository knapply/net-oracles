# Local reaching centrality {#concept-top}

Family: [Centrality](index.html). Subfamily: Local and structural scores. Concept id: `local_reaching_centrality`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(n=|V|\)</td><td>number of nodes</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): number of edges, or the total of the edge lengths for a weighted graph; \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr><tr><td>\(R(i)\)</td><td>nodes reachable from \(i\) by directed paths, \(i\) excluded</td></tr><tr><td>\(\bar w_{ij}\)</td><td>mean weight of the edges on a shortest path from \(i\) to \(j\), where an edge of weight \(w\) has length \(W/w\) and \(W\) is the largest weight</td></tr></tbody></table></div>

## Definition {#concept-definition}

Global reaching centrality of a network (Mones et al.): the mean gap between the largest local reaching centrality and every node's, divided by n - 1.

<div class="formula-block"><p class="formula-name"><strong>Local reaching centrality (Mones et al. 2012)</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[C_R(i)=\frac{|R(i)|}{n-1}\quad\text{(unweighted)},\qquad C_R^{w}(i)=\frac{1}{n-1}\sum_{j\in R(i)}\bar w_{ij}\quad\text{(weighted)}\]</div><p class="formula-where">Share of the nodes that \(i\) can reach; the weighted form averages the edge weights along shortest paths.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Global reaching centrality</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[\mathrm{GRC}=\frac{1}{n-1}\sum_{i}\bigl(C_R^{\max}-C_R(i)\bigr)\]</div><p class="formula-where">Hierarchy measure of the network: mean gap between the largest local score and every node's; 0 when all nodes reach equally many nodes, 1 for a star oriented outward.</p></div>

With integer weights some nodes have several shortest paths (lengths W/w) whose edges have different mean weights, and each tool averages the path its search finds first: NetworkX settles ties in insertion order, the reference by node index (weighted\_dir has two such pairs from node 3, checked with nx.all\_shortest\_paths). No mapping that reproduces the tool's value is recorded, so the entry was not compared after mapping. Tolerance before mapping: abs 1e-12, rel 1e-09 (0 means exact equality). 2 comparisons differ and 68 agree.

**Conventions and tolerances.** Tolerance is the bound used when comparing a tool's values with the reference value: `abs` and `rel` (0 means exact).
