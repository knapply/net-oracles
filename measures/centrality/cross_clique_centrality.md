# Cross-clique centrality {#concept-top}

Family: [Centrality](index.html). Subfamily: Local and structural scores. Concept id: `cross_clique_centrality`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(\mathcal{K}\)</td><td>set of cliques of the graph (complete subgraphs)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Cross-clique centrality. Entries grouped here: Crossclique.

*Note:* Whether non-maximal cliques are counted is not recorded in the documentation read.

<div class="formula-block"><p class="formula-name"><strong>Cross-clique connectivity (Faghani and Nguyen 2013)</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[X(v)=\bigl|\{K\in\mathcal K:\ v\in K\}\bigr|\]</div><p class="formula-where">Number of cliques that contain \(v\). The documentation of the tool says that directed graphs are read as undirected and that multiple edges and loops are ignored.</p></div>
