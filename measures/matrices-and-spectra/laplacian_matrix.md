## Definition {#concept-definition}

Laplacian matrix. Entries grouped here: Gm laplacian; Magnetic laplacian matrix.

*Definition partly written:* The magnetic Laplacian (cat\_laplacian\_magnetic\_matrix) is known by name only, and the directed Laplacian of Chung (2005) is not among the checked sources, so only the undirected forms and the out-degree form are written.

<div class="formula-block"><p class="formula-name"><strong>Combinatorial Laplacian (Biggs 1974; Chung 1997)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[L=D-A\]</div><p class="formula-where">Symmetric, positive semidefinite for undirected input with non-negative weights; row sums are 0. For directed input \(L=D_{\text{out}}-A\) is the usual extension (out-degree Laplacian); it is not symmetric.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Normalized Laplacian (Chung 1997)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\mathcal L=I-D^{-1/2}AD^{-1/2},\qquad \mathcal L(u,u)=0\ \text{if }d_u=0\]</div><p class="formula-where">Entries \(1\) on the diagonal, \(-1/\sqrt{d_ud_v}\) for adjacent nodes. Chung sets the diagonal entry to 0 for a node of degree 0, which makes the formula defined with isolated nodes.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Random-walk Laplacian</strong> <span class="applies">applies to: any</span></p><div class="formula">\[L_{\mathrm{rw}}=I-D^{-1}A\]</div><p class="formula-where">Defined only when every degree (out-degree) is positive; rows sum to 0.</p></div>
