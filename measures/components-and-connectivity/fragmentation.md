# Fragmentation {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Connected components. Concept id: `fragmentation`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(s_k\)</td><td>size of component \(k\)</td></tr><tr><td>\(r_{ij}\)</td><td>1 if \(i\) can reach \(j\) (or \(j\) can reach \(i\)) along a path, else 0</td></tr></tbody></table></div>

## Definition {#concept-definition}

Fragmentation. Entries grouped here: Fragmentation.

<div class="formula-block"><p class="formula-name"><strong>Fragmentation of an undirected graph (Borgatti 2006)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[F=1-\frac{\sum_k s_k(s_k-1)}{n(n-1)}\]</div><p class="formula-where">Proportion of ordered pairs of distinct nodes that are not connected; 0 for a connected graph and 1 when no pair is connected. Defined for \(n\ge2\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Fragmentation of a directed graph</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[F=1-\frac{\#\{(i,j):i\ne j,\ r_{ij}=1\ \text{or}\ r_{ji}=1\}}{n(n-1)}\]</div><p class="formula-where">Proportion of ordered pairs with no path in either direction (weak fragmentation); the strong version counts pairs that are not mutually reachable.</p></div>
