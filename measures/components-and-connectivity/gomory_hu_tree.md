# Gomory-Hu and equivalent-flow trees {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Flows and flow trees. Concept id: `gomory_hu_tree`. 3 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(\lambda(s,t)\)</td><td>minimum \(s\)-\(t\) cut value in \(G\) with the edge weights as capacities</td></tr></tbody></table></div>

## Definition {#concept-definition}

The Gomory-Hu tree of an undirected network: each node's parent and the minimum cut value to it (Gusfield).

<div class="formula-block"><p class="formula-name"><strong>Gomory-Hu tree (Gomory and Hu 1961)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[T\ \text{a tree on }V:\ \lambda(s,t)=\min_{e\in T[s,t]}w_T(e)\ \text{and each tree edge}\ e\text{ defines a minimum cut of value }w_T(e)\]</div><p class="formula-where">A weighted tree that encodes the minimum cut value between every pair as the minimum edge weight on the tree path and also the cuts themselves; \(n-1\) maximum flows build it (Gusfield 1990). An equivalent flow tree keeps only the first property. The tree is not unique, the values it encodes are.</p></div>
