# Global minimum cut {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Cuts and separators. Concept id: `global_min_cut`. 3 measures.

## Notation {#concept-notation}

## Definition {#concept-definition}

Minimum cut between a set of sources and a set of sinks: its capacity, the source side and the crossing edges.

<div class="formula-block"><p class="formula-name"><strong>Minimum s-t cut (Ford and Fulkerson 1956)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\min_{S\ni s,\,t\notin S}w(S,V\setminus S)=\max\text{ flow value from }s\text{ to }t\]</div><p class="formula-where">Capacity of a smallest cut separating the source side from the sink side; equal to the maximum flow. The cut set is not unique: the source-side set of minimal and of maximal size differ.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Global minimum cut (Stoer and Wagner 1997)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\min_{\emptyset\ne S\subsetneq V}w(S,V\setminus S)\]</div><p class="formula-where">Smallest cut over all bipartitions of an undirected weighted graph; 0 for a disconnected graph; needs \(n\ge2\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Cut measures of a node-set pair</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\mathrm{cutsize}=w(S,T),\ \ \mathrm{ncut}=\tfrac{w(S,T)}{\mathrm{vol}(S)}+\tfrac{w(S,T)}{\mathrm{vol}(T)},\ \ \phi=\tfrac{w(S,T)}{\min(\mathrm{vol}(S),\mathrm{vol}(T))},\ \ h=\tfrac{w(S,T)}{\min(|S|,|T|)}\]</div><p class="formula-where">Cut size, normalized cut (Shi and Malik 2000), conductance (Kannan, Vempala and Vetta 2004), edge expansion for node sets \(S\) and \(T\); undefined when a volume or size is 0.</p></div>
