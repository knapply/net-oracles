## Definition {#concept-definition}

Disjoint paths. Entries grouped here: Disjoint paths; Gb disjoint paths.

<div class="formula-block"><p class="formula-name"><strong>Disjoint paths (Menger 1927)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\kappa(s,t)=\max\{|\mathcal Q|:\mathcal Q\text{ internally node-disjoint }s\text{-}t\text{ paths}\},\quad \lambda(s,t)=\max\{|\mathcal Q|:\mathcal Q\text{ edge-disjoint }s\text{-}t\text{ paths}\}\]</div><p class="formula-where">For non-adjacent \(s,t\), \(\kappa\) equals the minimum number of nodes separating them, and \(\lambda\) equals the minimum number of edges separating them (also for adjacent nodes). Computed as maximum flow (Ford and Fulkerson 1956). The path sets themselves are not unique; their number is.</p></div>
