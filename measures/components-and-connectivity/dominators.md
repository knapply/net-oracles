## Definition {#concept-definition}

Immediate dominator of every node reachable from the start node (the start's is itself); unreachable nodes get the none mark u32::MAX.

*Definition partly written:* cat\_dominator (python-igraph's dominator tree) is documented only and was never run; its return convention is not recorded.

<div class="formula-block"><p class="formula-name"><strong>Dominators (Cooper, Harvey and Kennedy 2001)</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[d\ \mathrm{dom}\ v\iff\text{every path from }r\text{ to }v\text{ contains }d\]</div><p class="formula-where">Defined for nodes reachable from \(r\); \(r\) dominates all and \(\mathrm{idom}(r)=r\) by convention. The immediate dominators form a tree.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Dominance frontier (Cytron et al. 1991)</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[\mathrm{DF}(d)=\{v:\exists p\in\mathrm{pred}(v),\ d\ \mathrm{dom}\ p,\ d\ \text{does not strictly dominate}\ v\}\]</div><p class="formula-where">The nodes where the dominance of \(d\) ends.</p></div>
