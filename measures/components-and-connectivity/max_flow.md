# Maximum flow {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Flows and flow trees. Concept id: `max_flow`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(c(e)\)</td><td>capacity of edge \(e\) (infinite if absent)</td></tr><tr><td>\(f\)</td><td>a flow: \(0\le f(e)\le c(e)\), conserved at every node except the source set \(S\) and sink set \(T\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Maximum flow from a set of sources to a set of sinks (Dinic), with the flow on every edge.

<div class="formula-block"><p class="formula-name"><strong>Maximum flow (Ford and Fulkerson 1956)</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[\max_f\ \sum_{e\text{ out of }S}f(e)-\sum_{e\text{ into }S}f(e)\quad\text{s.t. capacity and conservation}\]</div><p class="formula-where">The maximum value equals the minimum cut capacity (max-flow min-cut theorem). The value is unique, the flow on individual edges is not. Algorithms: augmenting paths (Edmonds and Karp 1972), blocking flows (Dinic 1970). A multi-source, multi-sink problem is reduced to one source and one sink with infinite-capacity arcs. An unbounded value results when an \(S\)-\(T\) path has infinite capacity.</p></div>
