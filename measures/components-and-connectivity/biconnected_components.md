# Biconnected components {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Articulation points, bridges and biconnected components. Concept id: `biconnected_components`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Biconnected components. Entries grouped here: Bicomponents; Biconnected.

<div class="formula-block"><p class="formula-name"><strong>Biconnected components (blocks; Hopcroft and Tarjan 1973)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[B\ \text{is a block}\iff B\text{ is a maximal connected subgraph without a cut point of its own}\]</div><p class="formula-where">The blocks partition the edges; two blocks share at most one node, which is then a cut point. A bridge is a block of two nodes; isolated nodes and (in the node-set listing) loops form no block with an edge between distinct nodes.</p></div>
