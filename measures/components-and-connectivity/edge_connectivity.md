# Edge connectivity {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Connectivity numbers. Concept id: `edge_connectivity`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(\lambda(s,t)\)</td><td>minimum number of edges whose removal separates \(s\) from \(t\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Global edge connectivity: the fewest edges whose removal disconnects the network.

<div class="formula-block"><p class="formula-name"><strong>Edge connectivity</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\lambda(G)=\min_{s\ne t}\lambda(s,t)=\min\{|F|:F\subseteq E,\ G-F\text{ disconnected}\}\]</div><p class="formula-where">The fewest edges whose removal disconnects the graph; 0 for a disconnected graph. For a single node it is 0 by convention. For a directed graph the strong edge connectivity (minimum over ordered pairs) is used.</p></div>
