# Condensation of strong components {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Connected components. Concept id: `condensation`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(S_1..S_c\)</td><td>strongly connected components</td></tr><tr><td>\(G^{*}\)</td><td>the condensation graph with one node per component</td></tr></tbody></table></div>

## Definition {#concept-definition}

Condensation of strong components. Entries grouped here: Condensation.

<div class="formula-block"><p class="formula-name"><strong>Condensation (Harary, Norman and Cartwright 1965)</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[G^{*}=(\{S_i\},\ \{(S_i,S_j):i\ne j,\ \exists u\in S_i,v\in S_j,(u,v)\in E\})\]</div><p class="formula-where">Contract each strongly connected component to a node; the result is a directed acyclic graph. The node-to-component mapping is determined up to the numbering of the components, which depends on the algorithm and on edge order.</p></div>
