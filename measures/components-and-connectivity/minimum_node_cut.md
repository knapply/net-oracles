# Minimum node cut {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Cuts and separators. Concept id: `minimum_node_cut`. 3 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(\kappa(G),\kappa(s,t)\)</td><td>node connectivity and local node connectivity</td></tr></tbody></table></div>

## Definition {#concept-definition}

A smallest set of nodes whose removal disconnects the network.

<div class="formula-block"><p class="formula-name"><strong>Minimum node cut</strong> <span class="applies">applies to: any</span></p><div class="formula">\[X^\star\in\arg\min\{|X|:X\subseteq V,\ G-X\ \text{disconnected}\},\qquad|X^\star|=\kappa(G)\]</div><p class="formula-where">A smallest set of nodes whose removal disconnects the graph, or (\(s\)-\(t\) form) separates \(s\) from \(t\) with \(|X|=\kappa(s,t)\) for non-adjacent \(s,t\). Not defined for a complete graph, and no \(s\)-\(t\) node cut exists for adjacent nodes. The set is not unique; its size is. A disconnected graph has the empty cut.</p></div>
