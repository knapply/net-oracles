# Bridges {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Articulation points, bridges and biconnected components. Concept id: `bridges`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(c(G)\)</td><td>number of connected components</td></tr></tbody></table></div>

## Definition {#concept-definition}

Bridges. Entries grouped here: Bridges.

<div class="formula-block"><p class="formula-name"><strong>Bridge (Harary 1969; Tarjan 1972)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[e\text{ is a bridge}\iff c(G-e)&gt;c(G)\]</div><p class="formula-where">An edge whose removal increases the number of components; equivalently an edge on no cycle. Found in linear time by depth-first search with low-link values (Tarjan 1972). Parallel edges are not bridges (removing one leaves the other), and loops never are.</p></div>
