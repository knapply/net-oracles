# Attracting components {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Connected components. Concept id: `attracting_components`. 4 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(\mathcal S\)</td><td>the strongly connected components of a directed graph</td></tr></tbody></table></div>

## Definition {#concept-definition}

Attracting components. Entries grouped here: Attracting; Attracting flags; Is attracting component; Number attracting components.

*Definition partly written:* Stated from the standard definition; no primary paper is cited in the sources. The two documented-only measures (cat\_attracting\_component, cat\_attracting\_component\_is, NetworkX) were never run.

<div class="formula-block"><p class="formula-name"><strong>Attracting component</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[S\in\mathcal S\text{ is attracting}\iff\text{no arc leaves }S:\ \{(u,v)\in E:u\in S,v\notin S\}=\emptyset\]</div><p class="formula-where">A strongly connected component with no outgoing arc to another component: a sink of the condensation. Every directed graph has at least one (for \(n\ge1\)). Isolated nodes are attracting components of size 1.</p></div>
