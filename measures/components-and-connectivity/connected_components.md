# Connected components {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Connected components. Concept id: `connected_components`. 5 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(u\leftrightarrow v\)</td><td>mutual reachability (strong components) or reachability ignoring direction (weak components)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Weak or strong components: a label for every node and the size of each component.

<div class="formula-block"><p class="formula-name"><strong>Connected components</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\mathcal C=\{[v]:v\in V\},\quad [v]=\{u:u\leftrightarrow v\}\]</div><p class="formula-where">The classes of the equivalence relation \(\leftrightarrow\): weak components (direction ignored; the components of an undirected graph) and strong components (mutually reachable by directed paths, Tarjan 1972; Kosaraju-Sharir 1981). Every node is in exactly one component; an isolate is a component of size 1.</p></div>
