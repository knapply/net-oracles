# Cut points (articulation points) {#concept-top}

Family: [Components and connectivity](index.html). Subfamily: Articulation points, bridges and biconnected components. Concept id: `cut_points`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\), \(m=|E|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(c(G)\)</td><td>number of connected components</td></tr></tbody></table></div>

## Definition {#concept-definition}

Cut points (articulation points). Entries grouped here: Cut points.

<div class="formula-block"><p class="formula-name"><strong>Articulation point (Hopcroft and Tarjan 1973)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[v\text{ is a cut point}\iff c(G-v)&gt;c(G)\]</div><p class="formula-where">A node whose removal (with its edges) increases the number of components. Isolated nodes are not cut points since removing one lowers the component count; a node of degree 1 is not a cut point.</p></div>
