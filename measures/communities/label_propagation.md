# Label propagation {#concept-top}

Family: [Communities](index.html). Subfamily: Other detection algorithms. Concept id: `label_propagation`. 3 measures.

## Definition {#concept-definition}

Label propagation communities: every node repeatedly takes the dominant label among the nodes it reads.

<div class="formula-block"><p class="formula-name"><strong>Label propagation (Raghavan, Albert and Kumara 2007)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\ell_v\leftarrow\arg\max_{\ell}\sum_{u\in N(v):\ell_u=\ell}A_{vu}\]</div><p class="formula-where">Each node repeatedly takes the label with the largest total weight among its neighbours; started with a unique label per node and run until every node has a label that is a maximum among its neighbours (or for a fixed number of rounds); ties between labels are broken at random. Results are random and depend on the update order (synchronous, asynchronous, semi-synchronous per Cordasco and Gargano 2010; queue-based fast version per Traag and Subelj 2023). A node with no neighbour keeps its label.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Stop condition</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\forall v:\ \sum_{u\in N(v):\ell_u=\ell_v}A_{vu}=\max_\ell\sum_{u\in N(v):\ell_u=\ell}A_{vu}\]</div><p class="formula-where">The labelling is stable when each node has a label that is a maximum among the neighbours' labels.</p></div>
