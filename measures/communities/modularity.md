# Modularity {#concept-top}

Family: [Communities](index.html). Subfamily: Partition and cover quality. Concept id: `modularity`. 3 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target (the ends of an undirected edge are interchangeable)</td></tr><tr><td>\(c_i\)</td><td>community (group) of node \(i\) in a partition \(\mathcal P\) of \(V\); \(\delta(c_i,c_j)=1\) when \(i,j\) are in the same community</td></tr><tr><td>\(A_{ij}\)</td><td>weight of the edges from \(i\) to \(j\) (the edge count for an unweighted graph, parallel edges added); for an undirected graph \(A\) is symmetric and a self-loop adds 2 to \(A_{ii}\)</td></tr><tr><td>\(k_i=\sum_jA_{ij}\)</td><td>degree (strength) of \(i\)</td></tr><tr><td>\(m=\tfrac12\sum_{ij}A_{ij}\)</td><td>total edge weight; \(2m=\sum_ik_i\)</td></tr><tr><td>\(\gamma\)</td><td>resolution parameter (1 for standard modularity)</td></tr><tr><td>\(k_i^{\mathrm{out}},k_j^{\mathrm{in}}\)</td><td>out-degree of \(i\) and in-degree of \(j\) of a directed graph; \(m\) the total arc weight</td></tr></tbody></table></div>

## Definition {#concept-definition}

Modularity. Entries grouped here: Modularity; Modularity nx; Modularity State.

*Definition partly written:* cat\_modularity\_state (graph-tool's modularity state object) is documented only and was never run; what it exposes beyond the modularity value is not recorded in the sources.

<div class="formula-block"><p class="formula-name"><strong>Modularity (Newman and Girvan 2004; Newman 2006)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[Q=\frac1{2m}\sum_{ij}\Bigl(A_{ij}-\gamma\frac{k_ik_j}{2m}\Bigr)\delta(c_i,c_j)=\sum_c\Bigl[\frac{L_c}{m}-\gamma\Bigl(\frac{d_c}{2m}\Bigr)^2\Bigr]\]</div><p class="formula-where">Fraction of the edge weight inside communities minus the fraction expected in the configuration model with the same degrees; \(L_c\) is the weight inside community \(c\), \(d_c\) the total degree of \(c\). \(\gamma\) is the resolution parameter of Reichardt and Bornholdt 2006. Defined for \(m&gt;0\); with \(m=0\) it is 0/0.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Directed modularity (Leicht and Newman 2008)</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[Q=\frac1m\sum_{ij}\Bigl(A_{ij}-\gamma\frac{k_i^{\mathrm{out}}k_j^{\mathrm{in}}}{m}\Bigr)\delta(c_i,c_j)\]</div><p class="formula-where">The null model keeps out- and in-degrees; defined for \(m&gt;0\).</p></div>
