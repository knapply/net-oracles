# Infomap {#concept-top}

Family: [Communities](index.html). Subfamily: Other detection algorithms. Concept id: `infomap`. 1 measure.

## Definition {#concept-definition}

Infomap. Entries grouped here: Infomap.

<div class="formula-block"><p class="formula-name"><strong>Map equation (Rosvall and Bergstrom 2008; Rosvall, Axelsson and Bergstrom 2009)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[L(\mathsf M)=q_\curvearrowright H(\mathcal Q)+\sum_{i}p^i_\circlearrowright H(\mathcal P^i)\]</div><p class="formula-where">Expected description length per step of a random walk under a two-level code for partition \(\mathsf M\); \(H(\mathcal Q)\) is the entropy of the module-exit rates \(q_{i\curvearrowright}/q_\curvearrowright\) and \(H(\mathcal P^i)\) that of the module-exit and node rates within module \(i\) over \(p^i_\circlearrowright\). The partition minimizing \(L\) is reported; the minimization is a stochastic heuristic. Needs a random walk, so at least one edge.</p></div>
