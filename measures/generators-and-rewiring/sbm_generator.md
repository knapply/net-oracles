# Stochastic block model generator {#concept-top}

Family: [Generators and rewiring](index.html). Subfamily: Block models. Concept id: `sbm_generator`. 2 measures.

## Definition {#concept-definition}

Stochastic block model generator. Entries grouped here: Sbm random graph; Stochastic block model generator.

<div class="formula-block"><p class="formula-name"><strong>Stochastic block model (Holland, Laskey and Leinhardt 1983)</strong> <span class="applies">applies to: any, simple</span></p><div class="formula">\[\Pr(A_{ij}=1)=\omega_{b_ib_j}\ \text{independently for each pair}\]</div><p class="formula-where">Pairs are independent given the block assignment. A generator returns a random sample, so a result is reproducible only for a fixed seed and random generator; tools use different generators.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Degree-corrected block model (Karrer and Newman 2011)</strong> <span class="applies">applies to: any, multigraph</span></p><div class="formula">\[A_{ij}\sim\mathrm{Poisson}\bigl(\theta_i\theta_j\,\omega_{b_ib_j}\bigr)\]</div><p class="formula-where">Parallel edges and loops are allowed in this multigraph form; \(\theta\) is normalized within each block.</p></div>
