# G(n, p) random graph {#concept-top}

Family: [Generators and rewiring](index.html). Subfamily: Classic random graphs. Concept id: `gnp_random_graph`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(n\)</td><td>number of nodes</td></tr><tr><td>\(N\)</td><td>number of node pairs: \(\binom n2\) (undirected), \(n(n-1)\) (directed), plus \(n\) if loops are allowed</td></tr><tr><td>\(m\)</td><td>number of edges</td></tr><tr><td>\(p\)</td><td>edge probability</td></tr></tbody></table></div>

## Definition {#concept-definition}

G(n, p) random graph. Entries grouped here: G(n, p) random graph; Gnp.

<div class="formula-block"><p class="formula-name"><strong>G(n,p) (Gilbert 1959; Erdos and Renyi 1959)</strong> <span class="applies">applies to: any, simple</span></p><div class="formula">\[\Pr(G)=p^{m(G)}(1-p)^{N-m(G)},\qquad 0\le p\le1\]</div><p class="formula-where">Each of the \(N\) possible edges is present independently with probability \(p\). A generator returns a random sample, so a result is reproducible only for a fixed seed and random generator; tools use different generators.</p></div>
