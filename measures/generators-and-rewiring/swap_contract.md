# Edge swap and contract {#concept-top}

Family: [Generators and rewiring](index.html). Subfamily: Rewiring and randomization. Concept id: `swap_contract`. 1 measure.

## Definition {#concept-definition}

Connectivity-preserving double edge swaps of a connected undirected network, as the rewired edge list and the number of swaps kept.

*Definition partly written:* Only the degree-preserving double edge swap is written (Maslov and Sneppen 2002). The windowed connected swap of NetworkX and the directed three-edge swap are named in the sources and their rules are not written here; the checked contract is stated as a property of the result.

<div class="formula-block"><p class="formula-name"><strong>Double edge swap (Maslov and Sneppen 2002)</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[\{(a,b),(c,d)\}\ \to\ \{(a,d),(c,b)\}\quad\text{if }a,b,c,d\text{ are distinct and }(a,d),(c,b)\notin E\]</div><p class="formula-where">Two edges are chosen at random and their endpoints exchanged; every degree is unchanged. Repeated swaps sample graphs with the same degree sequence. A swap that would create a loop or a duplicate edge is rejected. A generator returns a random sample, so a result is reproducible only for a fixed seed and random generator; tools use different generators.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Contract of a result</strong> <span class="applies">applies to: any, simple</span></p><div class="formula">\[\deg_{E'}(v)=\deg_E(v)\ \forall v,\qquad |E'|=|E|,\qquad E'\ \text{simple}\ (\text{and connected for the connected variant})\]</div><p class="formula-where">Properties every rewired edge list \(E'\) must satisfy; two tools can be compared through this contract, not draw by draw, because their random generators differ.</p></div>
