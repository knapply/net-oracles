Family: [Generators and rewiring](index.html). Subfamily: Small-world, lattice and geometric models. Concept id: `geometric_graph`. 1 measure.

## Definition {#concept-definition}

Random geometric graph. Entries grouped here: Random geometric graph generator.

<div class="formula-block"><p class="formula-name"><strong>Random geometric graph (Penrose 2003)</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[i\sim j\iff\|x_i-x_j\|\le r\]</div><p class="formula-where">Nodes are random points, an edge joins points within distance \(r\). A generator returns a random sample, so a result is reproducible only for a fixed seed and random generator; tools use different generators.</p></div>
