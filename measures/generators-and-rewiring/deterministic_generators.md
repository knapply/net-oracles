## Definition {#concept-definition}

Deterministic generators. Entries grouped here: Deterministic generators.

*Definition partly written:* Standard graph definitions are written from the textbook (Harary 1969). The measure lists the generators of the comparison (complete, empty, path, cycle, star, wheel, ladder, grid, balanced tree, hypercube, complete bipartite) as one entry, so the variants key covers them together.

<div class="formula-block"><p class="formula-name"><strong>Named graphs (Harary 1969)</strong> <span class="applies">applies to: any, simple</span></p><div class="formula">\[K_n:\ i\sim j\ \forall i\ne j;\ \ P_n:\ i\sim i{+}1;\ \ C_n:\ P_n\ \text{plus}\ (n{-}1)\sim0;\ \ S_n:\ 0\sim i\ (i\ge1);\ \ W_n:\ C_{n-1}\ \text{plus a hub};\ \ Q_d:\ \{0,1\}^d,\ x\sim y\iff\text{they differ in one bit}\]</div><p class="formula-where">Complete, path, cycle, star, wheel and hypercube. \(Q_0\) has \(2^0=1\) node. The ladder is \(P_n\times K_2\), the grid \(P_a\times P_b\), the balanced tree has \(\sum_{i=0}^h r^i\) nodes, the complete bipartite graph \(K_{a,b}\) joins every node of one part to every node of the other.</p></div>
