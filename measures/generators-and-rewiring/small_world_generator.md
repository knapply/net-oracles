## Definition {#concept-definition}

Small-world generator. Entries grouped here: Small-world generator.

<div class="formula-block"><p class="formula-name"><strong>Watts-Strogatz model (Watts and Strogatz 1998)</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[\text{ring lattice }C_n^{k};\ \ \text{each edge }(i,i{+}j),\,j\le k/2,\ \text{is rewired with probability }p\text{ to a uniformly chosen new target}\]</div><p class="formula-where">Targets that would create a loop or a duplicate edge are not allowed; \(p=0\) leaves the lattice, \(p=1\) is close to a random graph. Defined for even \(k&lt;n\). A generator returns a random sample, so a result is reproducible only for a fixed seed and random generator; tools use different generators.</p></div>
