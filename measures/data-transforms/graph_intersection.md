# Graph intersection {#concept-top}

Family: [Data transforms](index.html). Subfamily: Graph operators. Concept id: `graph_intersection`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(n=|V|\)</td><td>number of nodes</td></tr><tr><td>\(m=|E|\)</td><td>number of edges</td></tr><tr><td>\(H=(V_H,E_H)\)</td><td>second graph, with the same edge conventions as \(G\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Graph intersection. Entries grouped here: Op intersection.

<div class="formula-block"><p class="formula-name"><strong>Intersection</strong> <span class="applies">applies to: any</span></p><div class="formula">\[V(G\cap H)=V\cap V_H,\qquad E(G\cap H)=E\cap E_H\]</div><p class="formula-where">Nodes and edges present in both graphs; with a common node set it is the graph of the common edges.</p></div>
