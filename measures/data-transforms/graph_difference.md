# Graph difference {#concept-top}

Family: [Data transforms](index.html). Subfamily: Graph operators. Concept id: `graph_difference`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(n=|V|\)</td><td>number of nodes</td></tr><tr><td>\(m=|E|\)</td><td>number of edges</td></tr><tr><td>\(H=(V_H,E_H)\)</td><td>second graph, with the same edge conventions as \(G\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Graph difference. Entries grouped here: Op difference.

<div class="formula-block"><p class="formula-name"><strong>Difference</strong> <span class="applies">applies to: any</span></p><div class="formula">\[V(G-H)=V,\qquad E(G-H)=E\setminus E_H\]</div><p class="formula-where">Edges of \(G\) that are not edges of \(H\), on the node set of \(G\); both graphs must be on the same node set for the formula to compare edges of the same nodes. For an undirected graph the edge \(uv\) equals \(vu\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Symmetric difference</strong> <span class="applies">applies to: any</span></p><div class="formula">\[E(G\,\triangle\,H)=(E\setminus E_H)\cup(E_H\setminus E)\]</div><p class="formula-where">Edges in exactly one of the two graphs.</p></div>
