# Graph union {#concept-top}

Family: [Data transforms](index.html). Subfamily: Graph operators. Concept id: `graph_union`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(n=|V|\)</td><td>number of nodes</td></tr><tr><td>\(m=|E|\)</td><td>number of edges</td></tr><tr><td>\(H=(V_H,E_H)\)</td><td>second graph, with the same edge conventions as \(G\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Graph union. Entries grouped here: Op union.

<div class="formula-block"><p class="formula-name"><strong>Union (Harary 1969)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[V(G\cup H)=V\cup V_H,\qquad E(G\cup H)=E\cup E_H\]</div><p class="formula-where">Nodes and edges present in at least one of the graphs; common nodes are identified.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Disjoint union</strong> <span class="applies">applies to: any</span></p><div class="formula">\[G+H:\quad V=V\sqcup V_H,\qquad E=E\sqcup E_H\]</div><p class="formula-where">The two node sets are taken as disjoint (relabelled if needed), so no node or edge is shared and the number of nodes is \(|V|+|V_H|\).</p></div>

## Variants {#concept-variants}

<div class="table-wrapper"><table class="variants"><thead><tr><th>Variant</th><th>Measure id</th><th>Tools</th><th>What changes</th></tr></thead><tbody><tr><td><a href="#op_union">Op union</a></td><td><code>op_union</code></td><td>5</td><td>Either the union (common nodes identified) or the disjoint union (nodes relabelled apart), and the all-graphs forms that fold several graphs; which of the two a function computes is part of its definition.</td></tr></tbody></table></div>
