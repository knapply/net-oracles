# Dyad census {#concept-top}

Family: [Descriptive statistics](index.html). Subfamily: Reciprocity, dyad and triad census. Concept id: `dyad_census`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target; the simple reading merges parallel edges and drops loops</td></tr><tr><td>\(M,A,N\)</td><td>numbers of mutual, asymmetric and null dyads among the \(\binom n2\) unordered node pairs: both arcs present, exactly one arc, no arc</td></tr></tbody></table></div>

## Definition {#concept-definition}

Dyad census. Entries grouped here: Dyad census (mutual, asymmetric, null).

<div class="formula-block"><p class="formula-name"><strong>Dyad census (Holland and Leinhardt 1976)</strong> <span class="applies">applies to: directed, simple</span></p><div class="formula">\[M+A+N=\binom n2\]</div><p class="formula-where">Every unordered pair of distinct nodes is in exactly one of three states; \(M\) is the number of reciprocated pairs, \(A\) the asymmetric ones.</p></div>
