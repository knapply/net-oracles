# Triad census {#concept-top}

Family: [Descriptive statistics](index.html). Subfamily: Reciprocity, dyad and triad census. Concept id: `triad_census`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target; the simple reading merges parallel edges and drops loops</td></tr><tr><td>\(T\)</td><td>set of the 16 isomorphism classes of directed triads in MAN order: 003, 012, 102, 021D, 021U, 021C, 111D, 111U, 030T, 030C, 201, 120D, 120U, 120C, 210, 300</td></tr><tr><td>\(\mathrm{type}(i,j,k)\)</td><td>class of the subgraph induced by the nodes \(i,j,k\), determined by its mutual, asymmetric and null dyads and their orientation</td></tr></tbody></table></div>

## Definition {#concept-definition}

The 16 triad counts in MAN order (Holland and Leinhardt), one value per triad type.

<div class="formula-block"><p class="formula-name"><strong>Triad census (Holland and Leinhardt 1976)</strong> <span class="applies">applies to: directed, simple</span></p><div class="formula">\[N_t=\bigl|\{\{i,j,k\}\subseteq V:\mathrm{type}(i,j,k)=t\}\bigr|,\qquad \sum_{t\in T}N_t=\binom n3\]</div><p class="formula-where">Counts of each triad class over all unordered node triples; defined for \(n\ge3\) (for \(n&lt;3\) there are no triples and all counts are 0). Batagelj and Mrvar 2001 compute it in subquadratic time.</p></div>
