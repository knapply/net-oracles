# Triangle count {#concept-top}

Family: [Descriptive statistics](index.html). Subfamily: Clustering and transitivity. Concept id: `triangle_count`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target; the simple reading merges parallel edges and drops loops</td></tr><tr><td>\(A\)</td><td>adjacency matrix of the simple undirected reading</td></tr></tbody></table></div>

## Definition {#concept-definition}

Number of triangles at each node of the simple undirected reading of the network.

<div class="formula-block"><p class="formula-name"><strong>Triangles at a node</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[t_i=\tfrac12\,(A^3)_{ii}=\bigl|\{\{j,h\}\subseteq N(i): a_{jh}=1\}\bigr|\]</div><p class="formula-where">Number of triangles that contain node \(i\); every triangle is counted once at each of its three nodes, so the total is \(\tfrac13\sum_i t_i\). Defined for every graph (0 when there are none); triangle listing algorithms are due to Chiba and Nishizeki 1985.</p></div>
