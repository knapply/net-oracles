# Density {#concept-top}

Family: [Descriptive statistics](index.html). Subfamily: Density and degree distribution. Concept id: `density`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target; the simple reading merges parallel edges and drops loops</td></tr><tr><td>\(n=|V|\)</td><td>number of nodes</td></tr><tr><td>\(m\)</td><td>number of edges (arcs for a directed graph)</td></tr><tr><td>\(n_1,n_2\)</td><td>sizes of the two node classes of a two-mode graph</td></tr></tbody></table></div>

## Definition {#concept-definition}

Density. Entries grouped here: Density; Twomode / density.

<div class="formula-block"><p class="formula-name"><strong>Density (Wasserman and Faust 1994)</strong> <span class="applies">applies to: simple</span></p><div class="formula">\[\Delta=\frac{2m}{n(n-1)}\;\text{(undirected)},\qquad \Delta=\frac{m}{n(n-1)}\;\text{(directed)}\]</div><p class="formula-where">Fraction of the possible ties that exist, on a simple graph without loops. Defined for \(n\ge2\); the denominator is 0 for \(n=1\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Density allowing loops</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\Delta_\circ=\frac{m}{n^2}\;\text{(directed)},\qquad \Delta_\circ=\frac{m}{n(n+1)/2}\;\text{(undirected)}\]</div><p class="formula-where">Possible ties include the \(n\) loops. Defined for \(n\ge1\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Two-mode density</strong> <span class="applies">applies to: two_mode, bipartite</span></p><div class="formula">\[\Delta_{12}=\frac{m}{n_1n_2}\]</div><p class="formula-where">Ties between the classes over the possible \(n_1n_2\); defined when both classes are non-empty.</p></div>
