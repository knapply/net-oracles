# Wiener index {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Distance summaries. Concept id: `wiener_index`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr><tr><td>\(k_u\)</td><td>degree of node \(u\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Sum of the distances over unordered pairs (ordered pairs in a directed network); infinite unless connected.

<div class="formula-block"><p class="formula-name"><strong>Wiener index (Wiener 1947)</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[W(G)=\sum_{\{s,t\}\subseteq V}d(s,t)\]</div><p class="formula-where">Sum of distances over unordered pairs of distinct nodes (ordered pairs for a directed graph); infinite unless (strongly) connected; 0 for one node.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Hyper-Wiener index (Randic 1993; Klein, Lukovits and Gutman 1995)</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[WW(G)=\tfrac12\sum_{\{s,t\}}\bigl(d(s,t)+d(s,t)^2\bigr)\]</div><p class="formula-where">Includes a factor \(\tfrac12\); a sum without the \(\tfrac12\) is twice the published value.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Schultz index (Schultz 1989)</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[MTI(G)=\sum_{\{s,t\}}(k_s+k_t)\,d(s,t)\]</div><p class="formula-where">Degree-weighted sum of distances.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Gutman index (Gutman 1994)</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[\mathrm{Gut}(G)=\sum_{\{s,t\}}k_sk_t\,d(s,t)\]</div><p class="formula-where">Product-of-degrees weighted sum of distances.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Harmonic diameter (Marchiori and Latora 2000)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[H(G)=\frac{n(n-1)}{\sum_{s\ne t}1/d(s,t)}\]</div><p class="formula-where">Harmonic mean distance over ordered pairs; unreachable pairs contribute \(1/\infty=0\), so it is defined on disconnected graphs when at least one pair is reachable.</p></div>
