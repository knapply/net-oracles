# Radius {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Distance summaries. Concept id: `radius`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(\varepsilon(v)\)</td><td>eccentricity: largest distance from \(v\) (over reached nodes in the finite convention)</td></tr></tbody></table></div>

## Definition {#concept-definition}

The smallest eccentricity (NaN for a network without nodes).

<div class="formula-block"><p class="formula-name"><strong>Radius (Harary 1969)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\mathrm{rad}(G)=\min_{v\in V}\varepsilon(v)\]</div><p class="formula-where">Smallest eccentricity. With the connected-graph eccentricity it is infinite for a disconnected graph; with the reached-nodes eccentricity isolated nodes contribute 0. Not defined for the empty graph (minimum over no nodes).</p></div>
