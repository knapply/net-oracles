## Definition {#concept-definition}

Path counts. Entries grouped here: Paths count.

<div class="formula-block"><p class="formula-name"><strong>Shortest-path counts (Brandes 2001)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\sigma_s(v)=\sum_{u\in P_s(v)}\sigma_s(u),\qquad \sigma_s(s)=1\]</div><p class="formula-where">Count of shortest paths from \(s\) by dynamic programming along the shortest-path predecessors. Parallel edges are distinct edges and give distinct paths. \(\sigma_s(v)=0\) when \(v\) is unreachable. With zero-length edges a zero-length cycle would make the number of shortest paths infinite.</p></div>
