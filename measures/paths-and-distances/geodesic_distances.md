# Geodesic distances {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Shortest paths. Concept id: `geodesic_distances`. 6 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr><tr><td>\(\ell(u,v)\)</td><td>length of the edge from \(u\) to \(v\); the shortest of parallel edges is used</td></tr><tr><td>\(h\)</td><td>node potential from Bellman-Ford used by Johnson's reweighting</td></tr></tbody></table></div>

## Definition {#concept-definition}

Geodesic distances. Entries grouped here: Distances; Fw tree; Johnson lengths; Paths all pairs; Paths floyd warshall; Paths johnson.

<div class="formula-block"><p class="formula-name"><strong>Geodesic distance</strong> <span class="applies">applies to: any</span></p><div class="formula">\[d(s,t)=\min_{\pi\in\mathcal P_{st}}\sum_{e\in\pi}\ell(e)\]</div><p class="formula-where">Minimum length over paths (walks give the same minimum when there is no negative cycle). Defined for every pair: finite, or \(\infty\) if \(t\) is unreachable; undefined (unbounded below) when a negative cycle is reachable from \(s\) and can reach \(t\).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Floyd-Warshall recursion (Floyd 1962)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[d^{(k)}(i,j)=\min\bigl(d^{(k-1)}(i,j),\,d^{(k-1)}(i,k)+d^{(k-1)}(k,j)\bigr)\]</div><p class="formula-where">All-pairs distances over intermediate nodes \(1..k\); \(d^{(0)}\) is the edge length matrix with 0 on the diagonal.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Johnson reweighting (Johnson 1977)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\hat\ell(u,v)=\ell(u,v)+h(u)-h(v)\ge0,\qquad d(s,t)=\hat d(s,t)-h(s)+h(t)\]</div><p class="formula-where">Potentials \(h\) from Bellman-Ford make all lengths non-negative so Dijkstra can be run from every source; not applicable when a negative cycle exists.</p></div>
