# All paths {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Path enumeration and counting. Concept id: `all_paths`. 3 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(\mathcal P_{st}\)</td><td>simple paths from \(s\) to \(t\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

All paths. Entries grouped here: All Directed Paths; Allpaths; Paths simple.

*Definition partly written:* cat\_allpaths (UCINET) and cat\_all\_directed\_path (JGraphT) are documented only and were never run; their options are not recorded in the sources.

<div class="formula-block"><p class="formula-name"><strong>Simple paths</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\mathcal P_{st}=\{(v_0=s,v_1,\dots,v_\ell=t):\ v_i\ \text{pairwise distinct},\ (v_{i-1},v_i)\in E\}\]</div><p class="formula-where">Paths without repeated nodes, of length \(\ell\ge0\) (a cutoff on \(\ell\) is a common option). The number of simple paths can grow exponentially with \(n\).</p></div>
