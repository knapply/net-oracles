# Global and local efficiency {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Efficiency and reachability. Concept id: `global_efficiency`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Global and local efficiency. Entries grouped here: Global and local efficiency; Swan efficiency.

*Definition partly written:* cat\_efficiency\_swan (netrankr's Swan efficiency) is documented only and was never run; its definition is not recorded in the sources.

<div class="formula-block"><p class="formula-name"><strong>Global efficiency (Latora and Marchiori 2001)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[E_{\mathrm{glob}}(G)=\frac{1}{n(n-1)}\sum_{s\ne t}\frac{1}{d(s,t)}\qquad\Bigl(\tfrac1\infty=0\Bigr)\]</div><p class="formula-where">Mean reciprocal distance over ordered pairs; defined for \(n\ge2\), 0 for an edgeless graph and 1 for a complete graph. Unreachable pairs contribute 0, so no connectivity assumption is needed.</p></div>
