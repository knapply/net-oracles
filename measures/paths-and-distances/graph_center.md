# Graph center {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Distance summaries. Concept id: `graph_center`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(\varepsilon(v)\)</td><td>eccentricity of \(v\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Nodes of smallest eccentricity; empty unless the network is (strongly) connected, as in NetworkX.

<div class="formula-block"><p class="formula-name"><strong>Center</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[\mathrm{Cen}(G)=\{v:\varepsilon(v)=\mathrm{rad}(G)\}\]</div><p class="formula-where">Nodes of smallest eccentricity. Defined for connected (strongly connected for directed) graphs, where all eccentricities are finite; otherwise the eccentricities are infinite or conventionally restricted, and the set is empty by convention in some tools.</p></div>
