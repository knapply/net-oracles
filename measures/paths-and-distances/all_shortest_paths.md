# All shortest paths {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Shortest paths. Concept id: `all_shortest_paths`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr><tr><td>\(\Pi_{st}\)</td><td>set of all shortest paths from \(s\) to \(t\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

All shortest paths. Entries grouped here: Paths all shortest.

<div class="formula-block"><p class="formula-name"><strong>All shortest paths</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\Pi_{st}=\{\pi\in\mathcal P_{st}:\ \ell(\pi)=d(s,t)\},\qquad|\Pi_{st}|=\sigma_{st}\]</div><p class="formula-where">Every path of length \(d(s,t)\) between the two nodes; paths are edge sequences. Empty when \(t\) is unreachable, and the single path of length 0 for \(s=t\).</p></div>
