# Diameter {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Distance summaries. Concept id: `diameter`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Longest shortest-path distance.

<div class="formula-block"><p class="formula-name"><strong>Diameter (Harary 1969)</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[\mathrm{diam}(G)=\max_{s,t\in V}d(s,t)\]</div><p class="formula-where">Largest distance; infinite when some pair is unreachable. Defined for \(n\ge1\) (0 for one node).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Diameter over reachable pairs</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\mathrm{diam}_R(G)=\max\{d(s,t):d(s,t)&lt;\infty\}\]</div><p class="formula-where">Longest finite shortest path: unreachable pairs are ignored, so it is defined for every graph with at least one node and is 0 when no two nodes are connected.</p></div>
