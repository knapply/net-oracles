# Barycenter {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Distance summaries. Concept id: `barycenter`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr><tr><td>\(s(v)\)</td><td>total distance \(\sum_{u\in V}d(v,u)\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

The nodes of smallest total distance to the others, and every node's total distance.

<div class="formula-block"><p class="formula-name"><strong>Barycenter</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[\mathrm{Bar}(G)=\arg\min_{v\in V}s(v),\qquad s(v)=\sum_{u\in V}d(v,u)\]</div><p class="formula-where">The nodes with the smallest total distance (largest Sabidussi closeness \(1/s\)). \(s(v)\) is infinite when a node is unreachable, so the set is defined for (strongly) connected graphs.</p></div>
