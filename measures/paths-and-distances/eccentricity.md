# Eccentricity {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Distance summaries. Concept id: `eccentricity`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr><tr><td>\(R(v)\)</td><td>nodes reachable from \(v\) (other than \(v\)); with direction ignored, the nodes of its component</td></tr></tbody></table></div>

## Definition {#concept-definition}

Each node's largest distance to the nodes it reaches.

<div class="formula-block"><p class="formula-name"><strong>Eccentricity (Harary 1969; Hage and Harary 1995)</strong> <span class="applies">applies to: connected</span></p><div class="formula">\[\varepsilon(v)=\max_{u\in V}d(v,u)\]</div><p class="formula-where">Largest distance from \(v\); infinite when some node cannot be reached. Defined for every node of a connected graph (0 for a single node).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Eccentricity over reached nodes</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\varepsilon_R(v)=\max_{u\in R(v)\cup\{v\}}d(v,u)\]</div><p class="formula-where">The largest finite distance: unreachable nodes are ignored, so it is defined on disconnected graphs and is 0 for a node that reaches nobody.</p></div>
