# Reachability {#concept-top}

Family: [Paths and distances](index.html). Subfamily: Efficiency and reachability. Concept id: `reachability`. 3 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\), \(n=|V|\); every edge has a source and a target</td></tr><tr><td>\(d(s,t)\)</td><td>length of a shortest path from \(s\) to \(t\): the number of edges, or the total of the edge lengths for a weighted graph; \(d(s,s)=0\); \(\infty\) if \(t\) cannot be reached from \(s\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Reachability. Entries grouped here: Reachability; Reachable Nodes; Reachdist.

*Definition partly written:* cat\_reachable (NetworKit) and cat\_reachdist (BCT) are documented only and were never run; what they return (a set of reachable nodes; the reachability matrix with distances) is not recorded beyond their names.

<div class="formula-block"><p class="formula-name"><strong>Reachability</strong> <span class="applies">applies to: any</span></p><div class="formula">\[s\rightsquigarrow t\iff d(s,t)&lt;\infty,\qquad R(s)=\{t\ne s:s\rightsquigarrow t\}\]</div><p class="formula-where">\(t\) is reachable from \(s\) if some path follows the edge directions from \(s\) to \(t\). Every node reaches itself by the empty path; the reachability matrix \(r_{st}=1\) iff \(s\rightsquigarrow t\). The relation is symmetric for undirected graphs.</p></div>
