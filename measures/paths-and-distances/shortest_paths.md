## Definition {#concept-definition}

Shortest-path lengths from one node by Delta-stepping; infinity for unreached nodes.

*Definition partly written:* cat\_path\_retrieve\_shortest (BCT: retrieving a shortest path from a matrix of predecessors) is documented only and was never run; its options are not recorded in the sources.

<div class="formula-block"><p class="formula-name"><strong>Single-source distances</strong> <span class="applies">applies to: any</span></p><div class="formula">\[d(s,v)=\min_{u:(u,v)\in E}\bigl(d(s,u)+\ell(u,v)\bigr),\quad d(s,s)=0\]</div><p class="formula-where">The Bellman optimality conditions that every algorithm solves; the shortest-path predecessors of \(v\) are the nodes \(u\) attaining the minimum (Bellman 1958).</p></div>

<div class="formula-block"><p class="formula-name"><strong>Dijkstra relaxation (Dijkstra 1959)</strong> <span class="applies">applies to: non-negative</span></p><div class="formula">\[\text{settle }v=\arg\min_{v\notin S}\tilde d(v);\ \ \tilde d(w)\leftarrow\min(\tilde d(w),\tilde d(v)+\ell(v,w))\]</div><p class="formula-where">Correct for non-negative lengths; bidirectional Dijkstra runs it from both ends. Breadth-first search (Moore 1959) is the unit-length case; Delta-stepping (Meyer and Sanders 2003) is a parallel bucketed variant.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Bellman-Ford with negative lengths</strong> <span class="applies">applies to: any</span></p><div class="formula">\[d^{(r)}(v)=\min\bigl(d^{(r-1)}(v),\min_{u}d^{(r-1)}(u)+\ell(u,v)\bigr),\quad r=1..n-1\]</div><p class="formula-where">Converges within \(n-1\) rounds when no negative cycle is reachable from the source; a change in round \(n\) signals a negative cycle (Goldberg and Radzik 1993 is a heuristic improvement). Potentials \(p\) with \(\ell+p(u)-p(v)\ge0\) reweight lengths.</p></div>

<div class="formula-block"><p class="formula-name"><strong>A* (Hart, Nilsson and Raphael 1968)</strong> <span class="applies">applies to: non-negative</span></p><div class="formula">\[f(v)=g(v)+h(v)\]</div><p class="formula-where">Expands nodes by \(f\); returns a shortest path when \(h\) is admissible (and, for closed-set variants, consistent). The distance is the same as Dijkstra's; only the nodes expanded differ.</p></div>
