# K-core decomposition {#concept-top}

Family: [Cohesion and subgroups](index.html). Subfamily: Cores, trusses and cohesive blocks. Concept id: `k_core`. 3 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\)</td></tr><tr><td>\(\deg_S(v)\)</td><td>degree of \(v\) within the subgraph induced by \(S\); for a directed graph the in-, out- or total degree as chosen</td></tr><tr><td>\(H_k\)</td><td>the \(k\)-core: the maximal induced subgraph in which every node has \(\deg\ge k\)</td></tr><tr><td>\(c(v)\)</td><td>core number: the largest \(k\) with \(v\in H_k\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

K-core decomposition. Entries grouped here: Core Decomposition Sequence; Core subset; Coreness.

*Definition partly written:* cat\_core\_decomposition\_sequence (NetworKit's core decomposition sequence) is documented only and was never run; its definition (presumably the removal order of the peeling) is not recorded in the sources.

<div class="formula-block"><p class="formula-name"><strong>Core number (Seidman 1983)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[c(v)=\max\{k: v\in H_k\},\qquad H_k=\text{the largest }S\text{ with }\min_{u\in S}\deg_S(u)\ge k\]</div><p class="formula-where">Every graph has a unique \(k\)-core for each \(k\), possibly empty. Computed in \(O(m)\) by repeated removal of the minimum-degree node (Batagelj and Zaversnik 2003). The definition is for simple graphs; counting loops and parallel edges in the degree is a convention.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Core subsets</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\text{shell}_k=\{v:c(v)=k\},\quad \text{crust}_k=\{v:c(v)\le k\},\quad \text{corona}_k=\{v:c(v)=k,\ \deg_{H_k}(v)=k\}\]</div><p class="formula-where">The \(k\)-shell, \(k\)-crust and \(k\)-corona derived from core numbers; \(k\)-core = \(\{v:c(v)\ge k\}\).</p></div>
