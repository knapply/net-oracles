# Lambda connectivity matrix {#concept-top}

Family: [Cohesion and subgroups](index.html). Subfamily: Relaxed cliques and subgroups. Concept id: `lambda_connectivity`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>simple undirected graph (direction ignored, parallel edges merged, loops dropped) with node set \(V\), \(n=|V|\)</td></tr><tr><td>\(\lambda(u,v)\)</td><td>edge connectivity between \(u\) and \(v\): the minimum number of edges whose removal disconnects them, equal to the maximum number of edge-disjoint \(u\)-\(v\) paths</td></tr></tbody></table></div>

## Definition {#concept-definition}

Edge connectivity between every pair of nodes, read off Gusfield's flow tree.

<div class="formula-block"><p class="formula-name"><strong>Lambda connectivity (Borgatti, Everett and Shirey 1990)</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[\lambda(u,v)=\min\{|F|:F\subseteq E,\ u,v\text{ in different components of }(V,E\setminus F)\}\]</div><p class="formula-where">Menger's theorem equates it with the maximum number of edge-disjoint paths; computed for all pairs from the \(n-1\) maximum flows of Gusfield's equivalent flow tree (Gusfield 1990), \(\lambda(u,v)\) being the minimum edge value on the tree path. Defined for \(u\ne v\); 0 for nodes in different components.</p></div>
