# Lambda sets {#concept-top}

Family: [Cohesion and subgroups](index.html). Subfamily: Relaxed cliques and subgroups. Concept id: `lambda_sets`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>simple undirected graph (direction ignored, parallel edges merged, loops dropped) with node set \(V\), \(n=|V|\)</td></tr><tr><td>\(\lambda(u,v)\)</td><td>edge connectivity between \(u\) and \(v\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Gusfield's equivalent flow tree: each node's parent and the edge connectivity to it (n - 1 maximum flows).

<div class="formula-block"><p class="formula-name"><strong>Lambda set (Borgatti, Everett and Shirey 1990)</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[S\ \text{is a lambda set}\iff \min_{i\ne j\in S}\lambda(i,j)&gt;\max_{i\in S,\,k\notin S}\lambda(i,k)\]</div><p class="formula-where">A set that is more connected internally than to any outside node. The nodes with \(\lambda\ge k\) to each other form an equivalence relation, so for each \(k\) the classes with at least two members are nested lambda sets; they are read off Gusfield's equivalent flow tree (\(n-1\) maximum flows) listing each node's parent and the connectivity to it.</p></div>
