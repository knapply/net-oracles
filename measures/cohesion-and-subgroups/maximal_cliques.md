# Maximal cliques {#concept-top}

Family: [Cohesion and subgroups](index.html). Subfamily: Cliques. Concept id: `maximal_cliques`. 2 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>simple undirected graph (direction ignored, parallel edges merged, loops dropped) with node set \(V\), \(n=|V|\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Every maximal clique with at least min\_size members, in lexicographic order.

*Definition partly written:* cat\_clique\_detect (NetworKit) is documented only and was never run; its options (minimum size, callback) are not recorded in the sources.

<div class="formula-block"><p class="formula-name"><strong>Maximal cliques (Bron and Kerbosch 1973)</strong> <span class="applies">applies to: undirected, simple</span></p><div class="formula">\[\mathcal M(G)=\{S\subseteq V: S\text{ is a clique and no }S'\supsetneq S\text{ is a clique}\}\]</div><p class="formula-where">Cliques that cannot be extended by any node. The set is determined by the graph; the order of listing and the minimum-size filter are conventions of the tool. The number of maximal cliques can be exponential (\(3^{n/3}\) at most). Isolated nodes are maximal cliques of size 1.</p></div>
