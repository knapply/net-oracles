# Assortativity coefficient {#concept-top}

Family: [Mixing and assortativity](index.html). Subfamily: Assortativity. Concept id: `assortativity_coefficient`. 4 measures.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(e_{ij}\)</td><td>fraction of edges that join a node of class \(i\) (source) to a node of class \(j\) (target); sums to 1. For an undirected graph each edge is counted in both orders, so \(e\) is symmetric</td></tr><tr><td>\(a_i=\sum_j e_{ij},\; b_j=\sum_i e_{ij}\)</td><td>fractions of edge ends at the source and at the target side in class \(i\), respectively \(j\)</td></tr><tr><td>\(x_i,\,y_j\)</td><td>values (a node property such as degree) at the source of an edge and at the target of an edge</td></tr><tr><td>\(\sigma_a,\sigma_b\)</td><td>standard deviations of \(a_i\) and \(b_j\) as distributions over the property values: \(\sigma_a^2=\sum_i a_i x_i^2-(\sum_i a_i x_i)^2\)</td></tr><tr><td>\(\mathrm{Tr}\,e\)</td><td>trace of \(e\): \(\sum_i e_{ii}\)</td></tr></tbody></table></div>

## Definition {#concept-definition}

Assortativity coefficient. Entries grouped here: Assort; Assortativity degree; Assortativity nominal; Assortativity values.

<div class="formula-block"><p class="formula-name"><strong>Assortativity by a scalar property (Newman 2002, 2003)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[r=\frac{\sum_{jk} jk\,(e_{jk}-a_j b_k)}{\sigma_a\sigma_b}\]</div><p class="formula-where">Pearson correlation between the values at the two ends of an edge; with \(j,k\) the property values (degree measured as remaining degree in Newman 2002, equivalently the degree itself, since the correlation is shift-invariant). Defined when \(\sigma_a\sigma_b&gt;0\); a regular graph has zero variance, so r is not defined.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Assortativity by a categorical attribute (Newman 2003)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[r=\frac{\sum_i e_{ii}-\sum_i a_i b_i}{1-\sum_i a_i b_i}\]</div><p class="formula-where">Compares the fraction of edges inside a class with the fraction expected if ends were paired at random with the same marginals; 1 for perfect within-class mixing. The denominator is 0 when all edge ends are in one class (\(\sum_i a_i b_i=1\)): not defined. Defined only when there is at least one edge, since the \(e_{ij}\) are fractions of edges.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Directed degree assortativity</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[r=\frac{\sum_{jk} jk\,(e_{jk}-a_j b_k)}{\sigma_a\sigma_b}\quad(j=\text{degree at source},\,k=\text{degree at target})\]</div><p class="formula-where">Same formula over the arcs, with the source value taken from one degree type (in or out) and the target value from another, giving the four in/out choices.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Weighted version</strong> <span class="applies">applies to: weighted</span></p><div class="formula">\[e_{jk}=\frac{\sum_{(u,v)}w_{uv}\,[x_u=j][y_v=k]}{\sum_{(u,v)}w_{uv}}\]</div><p class="formula-where">Each edge counts with its weight in the mixing fractions (and the degree values are strengths when strength assortativity is scored); weights non-negative and not all 0.</p></div>
