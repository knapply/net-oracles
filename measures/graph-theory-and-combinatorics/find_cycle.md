## Definition {#concept-definition}

Find a cycle. Entries grouped here: Find cycle; Nxs find cycle.

<div class="formula-block"><p class="formula-name"><strong>Cycle found by depth-first search (Tarjan 1972)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\text{a closed walk }v_0,e_1,v_1,\dots,e_k,v_0\ \text{with distinct edges, found when a depth-first search meets a node on its current path}\]</div><p class="formula-where">One cycle, as a list of edges, if the graph is not a forest (undirected) or not acyclic (directed); none otherwise. Which cycle depends on the start node and the order of neighbours. An undirected edge is written in the direction of travel.</p></div>
