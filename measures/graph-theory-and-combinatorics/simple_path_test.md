## Definition {#concept-definition}

Simple path test. Entries grouped here: Is simple path.

<div class="formula-block"><p class="formula-name"><strong>Simple path (Bondy and Murty 2008)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[v_i\ \text{pairwise distinct},\quad v_{i}v_{i+1}\in E\ \ (0\le i&lt;k)\]</div><p class="formula-where">A path with no repeated node; for a digraph each step follows an arc. A single node is a path of length 0, and the empty sequence is not a path.</p></div>
