# Traveling salesman {#concept-top}

Family: [Graph theory and combinatorics](index.html). Subfamily: Eulerian paths, Hamiltonian paths and tours. Concept id: `traveling_salesman`. 3 measures.

## Definition {#concept-definition}

Traveling salesman. Entries grouped here: St tsp; Traveling salesman (exact and heuristic); Tsp tour.

*Definition partly written:* cat\_tour\_tsp is known by name only; the heuristic or exact solver behind each documented entry is not recorded.

<div class="formula-block"><p class="formula-name"><strong>Travelling salesman problem</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\min_{\pi}\ \sum_{i}w(\pi_i,\pi_{i+1}),\quad \pi_{n+1}=\pi_1\]</div><p class="formula-where">The shortest closed tour through all nodes; NP-hard. On a graph that is not complete, tools take the metric closure (\(w:=d\)) so that a tour exists, and the tour is a walk that may repeat nodes of the original graph.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Christofides (1976)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\mathrm{len}(T)\le\tfrac32\,\mathrm{OPT}\quad(\text{metric }w)\]</div><p class="formula-where">Minimum spanning tree plus a minimum matching of its odd nodes, an Eulerian circuit, shortcut: a 3/2-approximation for metric instances.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Greedy nearest neighbour (Rosenkrantz, Stearns and Lewis 1977)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\pi_{i+1}=\arg\min_{v\notin\{\pi_1..\pi_i\}}w(\pi_i,v)\]</div><p class="formula-where">Go to the nearest unvisited node; ratio \(O(\log n)\) for metric instances.</p></div>
