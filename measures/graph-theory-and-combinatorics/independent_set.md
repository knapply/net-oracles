# Maximal independent set {#concept-top}

Family: [Graph theory and combinatorics](index.html). Subfamily: Independent sets and approximation. Concept id: `independent_set`. 3 measures.

## Definition {#concept-definition}

A random maximal independent set containing the start nodes (or one random node), nodes in increasing order.

<div class="formula-block"><p class="formula-name"><strong>Independent set (Haynes et al. 1998)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[I\ \text{independent}\iff \forall u,v\in I,\ u\ne v:\ uv\notin E\ (\text{and no loop at a node of }I)\]</div><p class="formula-where">No two members are adjacent. Maximal: no node can be added; maximum: of size \(\alpha(G)\) (NP-hard). \(I\) is independent iff \(V\setminus I\) is a vertex cover.</p></div>

<div class="formula-block"><p class="formula-name"><strong>Random maximal independent set (Luby 1986)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\text{start with the required nodes; add a uniformly random node not adjacent to the set until none is left}\]</div><p class="formula-where">The result is maximal but not maximum, and depends on the random draws; the required start nodes must themselves be independent.</p></div>
