# Triangle listing {#concept-top}

Family: [Graph theory and combinatorics](index.html). Subfamily: Triangles and local counts. Concept id: `triangle_list`. 1 measure.

## Notation {#concept-notation}

<div class="table-wrapper"><table class="notation"><thead><tr><th>Symbol</th><th>Meaning</th></tr></thead><tbody><tr><td>\(G=(V,E)\)</td><td>graph with node set \(V\) and edge set \(E\); every edge has a source and a target (the two ends of an undirected edge are interchangeable)</td></tr><tr><td>\(n=|V|\)</td><td>number of nodes</td></tr><tr><td>\(m=|E|\)</td><td>number of edges</td></tr><tr><td>\(\mathcal T\)</td><td>set of triangles</td></tr></tbody></table></div>

## Definition {#concept-definition}

Triangle listing. Entries grouped here: Triangle list.

<div class="formula-block"><p class="formula-name"><strong>Triangle listing (Latapy 2008; Ortmann and Brandes 2014)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[\mathcal T=\{(a,b,c):\ a&lt;b&lt;c,\ ab,bc,ac\in E\}\]</div><p class="formula-where">Each triangle once, as an ordered triple, on the simple graph underlying the input; \(|\mathcal T|\) is the number of triangles. Listing algorithms (edge iteration, node iteration, forward) all produce the same set.</p></div>
