## Definition {#concept-definition}

Every chordless (induced) cycle.

<div class="formula-block"><p class="formula-name"><strong>Chordless (induced) cycle (Dias et al. 2013)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[C=(v_1,\dots,v_k),\ k\ge3:\ v_iv_{i+1}\in E\ \text{and}\ v_iv_j\notin E\ \text{for non-consecutive}\ i,j\]</div><p class="formula-where">A cycle whose node set induces exactly the cycle: no chords. Every triangle is chordless; \(C_4\) with a diagonal is not. The cycle is counted once, regardless of start node and direction.</p></div>
