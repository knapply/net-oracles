## Definition {#concept-definition}

Bipartite coloring and test. Entries grouped here: Bipartite; Bipartite color; Is bipartite node set (bipartite).

<div class="formula-block"><p class="formula-name"><strong>Bipartite graph and 2-colouring (Bondy and Murty 2008)</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[G\ \text{bipartite}\iff\text{no odd cycle}\iff\exists c:\ c(u)\neq c(v)\ \forall uv\in E\]</div><p class="formula-where">In each component the colour of a node is the parity of its distance from a start node; the colouring is unique up to swapping the two colours in each component. A test of a node set \(X\) asks that every edge has exactly one end in \(X\).</p></div>
