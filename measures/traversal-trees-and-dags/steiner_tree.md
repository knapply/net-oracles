## Definition {#concept-definition}

Steiner tree. Entries grouped here: Steiner tree.

<div class="formula-block"><p class="formula-name"><strong>Steiner tree</strong> <span class="applies">applies to: undirected</span></p><div class="formula">\[T^{*}=\arg\min_{T\ \text{tree},\ K\subseteq V(T)}\sum_{e\in T}w(e)\]</div><p class="formula-where">A least-weight tree that contains all terminals and may contain other nodes; NP-hard, so tools return approximations: Kou, Markowsky and Berman (1981) compute a minimum spanning tree of the metric closure on \(K\) and expand it (factor 2); Mehlhorn (1988) computes the same bound faster.</p></div>
