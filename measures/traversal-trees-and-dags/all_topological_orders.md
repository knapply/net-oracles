# All topological orders {#concept-top}

Family: [Traversal, trees and DAGs](index.html). Subfamily: DAGs and topological order. Concept id: `all_topological_orders`. 2 measures.

## Definition {#concept-definition}

Every topological order of a DAG, in the sequence of Knuth and Szwarcfiter's algorithm.

<div class="formula-block"><p class="formula-name"><strong>Topological order and all of them (Knuth and Szwarcfiter 1974)</strong> <span class="applies">applies to: directed</span></p><div class="formula">\[\sigma\ \text{is a topological order}\iff \sigma(u)&lt;\sigma(v)\ \ \text{for every arc }(u,v)\in E\]</div><p class="formula-where">The set of all linear extensions of the partial order of the DAG; its size ranges from 1 (a total order) to \(n!\) (no arcs). The sequence in which an algorithm lists them is not part of the definition.</p></div>
