# Depth-first search {#concept-top}

Family: [Traversal, trees and DAGs](index.html). Subfamily: Traversal and orderings. Concept id: `depth_first_search`. 3 measures.

## Definition {#concept-definition}

Depth-first search. Entries grouped here: Dfs events; Dfs iterator; Edge dfs.

<div class="formula-block"><p class="formula-name"><strong>Depth-first search (Tarjan 1972)</strong> <span class="applies">applies to: any</span></p><div class="formula">\[\text{visit }v:\ \text{set }t_d(v);\ \text{for each neighbour }u\text{ of }v\text{ not yet visited: set }\pi(u)=v\text{ and visit }u;\ \text{set }t_f(v)\]</div><p class="formula-where">Each node is explored as deep as possible before backtracking. The order of neighbours decides which of several valid forests results. Arcs are classified tree, back (to an ancestor), forward (to a descendant) and cross; in an undirected graph only tree and back edges occur.</p></div>
